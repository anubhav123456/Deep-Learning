## Geometric Interpretation Basics for the MP Neuron

This lecture revises basic geometry so that it's easier to understand the **geometric interpretation of the McCulloch-Pitts (MP) neuron**.

### 1. Coordinate System

* Instead of using the usual **x-axis** and **y-axis**, the instructor uses:

  * $x_1 \to$ First input feature
  * $x_2 \to$ Second input feature
* The symbol **(y)** is reserved for the output of the neuron, so it isn't used as an axis.

---

### 2. Equation of a Line

The familiar equation of a line is:

$$y = mx + c$$

In machine learning notation, it becomes:

$$x_2 = mx_1 + c$$

Rearranging,

$$mx_1 - x_2 + c = 0$$

More generally, every line can be written as:

$$ax_1 + bx_2 + c = 0$$

This form is very important because it is the one used in machine learning.

---

### 3. Meaning of the Equation

Consider the line:

$$x_1 + x_2 - 2 = 0$$

Every point lying **on the line** satisfies:

$$x_1 + x_2 - 2 = 0$$

Examples:

* (2,0)
* (0,2)
* (1,1)

All give a value of **0**.

---

### 4. Points Above and Below the Line

The line divides the plane into two regions.

#### Above the line

For any point above the line,

$$ax_1 + bx_2 + c > 0$$

Example:

* Point $(1,2)$

$$1 + 2 - 2 = 1 > 0$$

---

#### Below the line

For any point below the line,

$$ax_1 + bx_2 + c < 0$$

Example:

* Point $(0,1)$

$$0 + 1 - 2 = -1 < 0$$

---

### 5. Three Possible Cases

For any point:

* **On the line**

$$ax_1 + bx_2 + c = 0$$

* **Above the line:**

$$ax_1 + bx_2 + c > 0$$

* **Below the line:**

$$ax_1 + bx_2 + c < 0$$

Thus, a line acts as a **boundary** separating two classes of points.

---

### 6. Relation to the Slope Form

The general equation

$$ax_1 + bx_2 + c = 0$$

can be rewritten as

$$x_2 = -\frac{a}{b}x_1 - \frac{c}{b}$$

where

* **Slope:**

$$m = -\frac{a}{b}$$

* **Intercept:**

$$p = -\frac{c}{b}$$

So both forms represent the same line.

---

### 7. Extension to Three Dimensions

When there are three input features ($(x_1, x_2, x_3)$), the equation becomes:

$$ax_1 + bx_2 + cx_3 + d = 0$$

In 3D:

* It represents a **plane** instead of a line.
* Points **on the plane** satisfy:

$$ax_1 + bx_2 + cx_3 + d = 0$$

* Points on one side satisfy:

$$ax_1 + bx_2 + cx_3 + d > 0$$

* Points on the other side satisfy:

$$ax_1 + bx_2 + cx_3 + d < 0$$

A plane separates the 3D space into two halves, just like a line separates the 2D plane.

---

## Key Takeaways

* Use **$(x_1, x_2)$** instead of $(x, y)$ because $y$ is the output of the neuron.
* Write every line in the form:

$$ax_1 + bx_2 + c = 0$$

* A line divides the plane into **two regions**:

  * Positive side ($>0$)
  * Negative side ($<0$)

* In 3D, the line becomes a **plane**:

$$ax_1 + bx_2 + cx_3 + d = 0$$

* **The most important idea:** A line or plane acts as a **decision boundary**, separating data points into different regions. This concept is the foundation for understanding how the **McCulloch-Pitts neuron** classifies inputs in the next lecture.
