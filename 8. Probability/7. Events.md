# Lecture Summary: Representing Classification as Probability Distributions

This lecture continues the discussion about true distributions, predicted distributions, and why probability distributions are important in classification.

---

### 1. Even a Certain Event Can Be Represented as a Probability Distribution

The instructor gives an example of a tournament with four teams:

$$\text{Teams: } \{A, B, C, D\}$$

Suppose the tournament has already finished and **Team A** actually won. We can represent this result in the usual way:

$$\text{Winner} = A$$

But we can also represent exactly the same information as a probability distribution:

| Team | A | B | C | D |
| :--- | :---: | :---: | :---: | :---: |
| **True Probability** | $1$ | $0$ | $0$ | $0$ |

This means:

$$P(A) = 1 \quad \text{and} \quad P(B) = P(C) = P(D) = 0$$

All the probability mass is assigned to the correct outcome.

---

### 2. Predicted Distribution Represents Uncertainty

Now imagine that you did not know who won. Based on your knowledge of the teams and previous matches, you make a prediction:

$$\hat{y} = [0.60,\ 0.20,\ 0.15,\ 0.05]$$

Meaning:

* **Team A:** $60\%$ chance of winning
* **Team B:** $20\%$ chance
* **Team C:** $15\%$ chance
* **Team D:** $5\%$ chance

Notice something important: You are not just predicting one class. Instead, you are expressing your **confidence or belief** across every possible class.

---

### 3. True Distribution vs. Predicted Distribution

If Team A actually won:

$$y = [1, 0, 0, 0]$$

But your prediction was:

$$\hat{y} = [0.6, 0.2, 0.15, 0.05]$$

Now the machine learning problem becomes:

> **How do we measure the difference between the true distribution ($y$) and the predicted distribution ($\hat{y}$)?**

One possible method is again **Squared Error Loss**:

$$\text{Loss} = \sum_{i=1}^{4}(y_i - \hat{y}_i)^2$$

However, as discussed in the previous lectures, squared error does not fully take advantage of the fact that these values are probabilities.

---

### 4. The Important Connection to Classification

This is the key idea of the lecture: A classification label such as $\text{Class} = A$ can also be represented as a probability distribution $[1, 0, 0, 0]$.

This is extremely important in machine learning. For example, if we have four possible classes $\{A, B, C, D\}$ and the correct answer is $A$, then:

* **True distribution:** $y = [1, 0, 0, 0]$
* **Predicted distribution:** $\hat{y} = [0.6, 0.2, 0.15, 0.05]$

Therefore, classification can be viewed as:

$$\text{True Probability Distribution } (y) \quad \text{vs.} \quad \text{Predicted Probability Distribution } (\hat{y})$$

The next step is to find a good loss function for comparing these two distributions.

---

### Main Takeaway

> **Even when we know the exact correct class, we can represent it as a probability distribution where the correct class has probability $1$ and every other class has probability $0$. This allows classification problems to be treated as the problem of comparing a true probability distribution with a model's predicted probability distribution.**

*This is the foundation that will eventually lead to understanding **one-hot encoding**, **Softmax**, and **Cross-Entropy Loss**.*
