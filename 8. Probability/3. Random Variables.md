# **Random Variables in Classification**

This lecture explains the formal definition of a **Random Variable** and demonstrates why probability and random variables are essential for understanding machine learning classification problems.

---

## 1. Formal Definition of a Random Variable

A **random variable** is a function that maps every outcome $\omega$ in the sample space/universal set ($\Omega$) to a specific value in a set of possible outputs:

$$f : \Omega \rightarrow \text{Values}$$

### Examples:

* **Grade Function:**

$$f_{\text{grade}}(\text{Student}) \in \{A, B, C\}$$

* **Height Function:**

$$f_{\text{height}}(\text{Student}) \in \{\text{Tall}, \text{Short}\}$$

Each outcome in the universal set maps to **exactly one** value.

---

## 2. Defining Events via Random Variables

Suppose we want the probability that a student receives grade $A$.

Instead of an informal description, we express this formally as the probability of the set of all students for whom the grade function outputs $A$:

$$\{\omega \in \Omega \mid f_{\text{grade}}(\omega) = A\}$$

where:

* $\omega$ = an individual outcome (a student)
* $f_{\text{grade}}$ = grade random variable function

The probability is evaluated as:

$$P(G = A) = \frac{\text{Number of students with Grade } A}{\text{Total students}}$$

---

## 3. Modular Attribute Representation

The primary advantage of random variables is that a single universal set can be evaluated across multiple attributes simultaneously:

| Random Variable | Target Domain | Output Values |
| --- | --- | --- |
| **$f_{\text{grade}}$** | Grade | $A, B, C$ |
| **$f_{\text{height}}$** | Height | $\text{Tall}, \text{Short}$ |
| **$f_{\text{age}}$** | Age Group | $\text{Young}, \text{Adult}$ |
| **$f_{\text{degree}}$** | Degree | $\text{B.Tech}, \text{M.Tech}, \text{Ph.D.}$ |
| **$f_{\text{branch}}$** | Branch | $\text{CSE}, \text{ECE}, \text{Math}$ |

---

## 4. Random Variables in Machine Learning

Replace students with input samples (e.g., images). The universal set becomes $\Omega = \{\text{All Images}\}$.

Define a discrete random variable called $Y$ representing the class label:

$$\text{Image} \xrightarrow{\quad Y \quad} \{0, 1\}$$

where:

* $0$ = No Text
* $1$ = Text

The model predicts class probabilities:

$$P(Y = 0) \quad \text{and} \quad P(Y = 1)$$

---

## 5. Binary vs. Multi-Class Classification

### Binary Classification

Predicts probabilities across two mutually exclusive classes:

| Predicted Class | Probability Output |
| --- | --- |
| **Text ($Y = 1$)** | $0.93$ |
| **No Text ($Y = 0$)** | $0.07$ |

### Multi-Class Classification

Extends to multiple discrete outcomes (e.g., an OCR model predicting Hindi consonants):

$$P(\text{Consonant} = \text{क}) = 0.70, \quad P(\text{Consonant} = \text{ख}) = 0.15, \quad \dots$$

```text
                     ┌──► P(Consonant = क) = 0.70
                     ├──► P(Consonant = ख) = 0.15
Input Image ─────────┼──► P(Consonant = ग) = 0.10
                     └──► P(Consonant = घ) = 0.05

```

---

## 6. Multiple Random Variables for a Single Input

A single input can map to multiple independent random variables simultaneously. For example, in an OCR task processing Devanagari script:

* **Consonant Variable:** $P(\text{Consonant} = \text{स})$
* **Vowel (Matra) Variable:** $P(\text{Vowel} = \text{े})$

---

## 7. Connection to Loss Functions

Classifiers output a **probability distribution** across all candidate classes, quantifying the model's confidence.

To measure how far predicted probabilities deviate from ground-truth labels during training, we require a specialized loss function: **Cross-Entropy Loss**.

---

## Key Takeaways

* A random variable $f: \Omega \rightarrow \text{Values}$ maps elements from a sample space to discrete or continuous values.
* In machine learning, inputs (e.g., images) form the sample space $\Omega$, while target labels are modeled as random variables.
* Machine learning classifiers output probability distributions over class outcomes.
* **Cross-Entropy Loss** is specifically designed to quantify the distance between predicted probability distributions and true labels.
