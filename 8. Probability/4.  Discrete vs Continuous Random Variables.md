# Discrete vs Continuous Random Variables

This lecture explains that **random variables can be either discrete or continuous**.

* **Discrete random variables** can take only a specific, countable set of values.

  * Example: Movie ratings → **1, 2, 3, 4, 5**
  * Example: Grades → **A, B, C**
  * You cannot normally have intermediate values like **1.2 rating** or a grade between A and B.

* **Continuous random variables** can take **any value within a range**.

  * Example: Height → 120 cm, 120.5 cm, 120.25 cm, etc.
  * Example: Weight → 45.1 kg, 45.23 kg, etc.
  * These values lie continuously on the **real number line**.

### Main point

> **Discrete = separate, countable values**
> **Continuous = any possible value within a range**
