# Why Probability Distributions Matter in Machine Learning

This lecture makes the main connection between probability theory and machine learning classification. The key idea is:

> **In a classification problem, both the true answer and the model's prediction can be represented as probability distributions. Training the model then becomes the problem of measuring the difference between these two distributions.**

---

### 1. Binary Classification Example: Text vs. No Text

Suppose we give a model an image containing the word **"Mumbai"**. The task is to predict whether the image contains text.

We define a class random variable $C \in \{0, 1\}$, where:

* $C = 0 \longrightarrow \text{No text}$
* $C = 1 \longrightarrow \text{Text present}$

Since we already know that the training image contains text, the true distribution is:

$$y = [0, 1]$$

| Class | No Text ($0$) | Text ($1$) |
| :--- | :---: | :---: |
| **True Probability** | $0$ | $1$ |

This is a **certain event**. We know with $100\%$ certainty that the image contains text.

---

### 2. The Model Produces a Predicted Probability

The image is passed through a model using the sigmoid function:

$$\hat{y} = \frac{1}{1 + e^{-(w^T x + b)}}$$

Suppose the image is $30 \times 30$ pixels. Then it has $30 \times 30 = 900$ input values/features. The model processes these inputs using weights ($w$) and bias ($b$).

If the sigmoid output is $0.7$, we interpret this as:

$$P(\text{Text}) = 0.7 \implies P(\text{No Text}) = 1 - 0.7 = 0.3$$

So the **predicted distribution** is:

$$\hat{y} = [0.3, 0.7]$$

* **Ideal prediction:** $[0, 1]$
* **Model's current prediction:** $[0.3, 0.7]$

---

### 3. Training Means Comparing These Two Distributions

Now we have:

* **True distribution:** $y = [0, 1]$
* **Predicted distribution:** $\hat{y} = [0.3, 0.7]$

To evaluate how bad the model's current prediction is, we calculate the difference:

$$\text{Loss} = \text{Difference}(y, \hat{y})$$

While we could use **Squared Error** ($\sum (y_i - \hat{y}_i)^2$), since these values are probabilities, we want a loss function naturally rooted in probability theory:

$$\boxed{\text{Cross-Entropy Loss}}$$

This loss will later be used during backpropagation to update the model's weights and biases.

---

### 4. Multi-Class Classification Example

The lecture then extends the same idea to recognizing English characters. Suppose an image contains the letter **'m'**.

Now the model has to choose between **26 possible classes** ($a, b, c, \dots, z$). This shifts the problem from binary to **multi-class classification**.

---

### 5. True Distribution in Multi-Class Classification

Since we know that the image actually contains 'm', the true probability distribution is:

$$y = [0, 0, 0, \dots, \underbrace{1}_{m}, \dots, 0]$$

Only the position corresponding to 'm' has a value of $1$; every other character has a probability of $0$. This is called a:

$$\boxed{\text{One-Hot Vector}}$$

For 26 English letters, it is a 26-dimensional vector containing **one $1$** and **twenty-five $0$s**.

---

### 6. Predicted Distribution

The model outputs probabilities for all 26 classes, such that:

$$\sum_{i=1}^{26}\hat{y}_i = 1$$

For example, if the model predicts $P(m) = 0.7$, the remaining $0.3$ probability mass is distributed among the other 25 characters:

$$\hat{y} = [0.01, 0.02, \dots, \underbrace{0.7}_{m}, \dots, 0.03]$$

---

### 7. Comparing True vs. Predicted Distributions

* **True distribution ($y$):** $[0, \dots, 1, \dots, 0]$
* **Predicted distribution ($\hat{y}$):** $[0.01, \dots, 0.7, \dots, 0.02]$

Now we calculate $\text{Difference}(y, \hat{y})$. Rather than using Squared Error ($\sum_{i=1}^{26}(y_i - \hat{y}_i)^2$), we use **Cross-Entropy Loss**.

---

### The Complete Flow

#### Binary Classification
$$\text{Image} \longrightarrow \text{Model + Sigmoid} \longrightarrow \hat{y} = [0.3, 0.7]$$
$$\text{Compare with } y = [0, 1] \longrightarrow \text{Calculate Loss} \longrightarrow \text{Update Weights}$$

#### Multi-Class Classification
$$\text{Image of 'm'} \longrightarrow \text{Model} \longrightarrow \hat{y} = [0.01, 0.02, \dots, 0.7, \dots]$$
$$\text{Compare with One-Hot } y = [0, 0, \dots, 1, \dots, 0] \longrightarrow \text{Calculate Loss}$$

---

### Main Takeaway

$$\boxed{\text{Classification} \longrightarrow \text{Probability Distribution} \longrightarrow \text{True } (y) \text{ vs. Predicted } (\hat{y}) \longrightarrow \text{Loss Function} \longrightarrow \text{Update Model}}$$

For every training example, the correct label is represented as a true probability distribution (a one-hot vector), while the neural network produces a predicted probability distribution. Training a classification model means measuring the difference between these two distributions and adjusting parameters to bring $\hat{y}$ closer to $y$.

*This serves as the exact foundation for understanding:* **Sigmoid $\rightarrow$ Binary Classification $\rightarrow$ One-Hot Encoding $\rightarrow$ Multi-Class Classification $\rightarrow$ Softmax $\rightarrow$ Cross-Entropy Loss.**
