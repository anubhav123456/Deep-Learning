# Basics of Probability Theory

#### Why Probability?

* The purpose of learning probability is to understand the **Cross-Entropy Loss** function.
* Before learning cross-entropy, we need to understand:
  * Probability
  * Random variables (later)
  * Their role in binary and multi-class classification.

---

## 1. Basic Properties of Probability

For any event $A$:

* **Probability is always non-negative:**

$$P(A) \ge 0$$

* **Probability can never exceed $1$:**

$$0 \le P(A) \le 1$$

This is why the **Sigmoid function** outputs values between **$0$ and $1$**—because its output represents a probability.

---

## 2. Disjoint (Mutually Exclusive) Events

Two or more events are **disjoint** if they **cannot happen at the same time**.

Example:
* A ball cannot be **both blue and red** simultaneously.

For two disjoint events:

$$P(A \cup B) = P(A) + P(B)$$

Similarly, for many disjoint events:

$$P(A_1 \cup A_2 \cup \cdots \cup A_n) = P(A_1) + P(A_2) + \cdots + P(A_n)$$

---

## 3. Ball Color Example

Imagine a box containing balls of five colors:

* Blue
* Green
* Red
* Yellow
* Orange

Each color represents a distinct event:

* $P(\text{Blue})$
* $P(\text{Green})$
* $P(\text{Red})$
* $P(\text{Yellow})$
* $P(\text{Orange})$

Since every ball has **only one color**, these events are **mutually exclusive (disjoint)**.

Therefore:

$$P(\text{Blue or Green or Red or Yellow or Orange}) = P(\text{B}) + P(\text{G}) + P(\text{R}) + P(\text{Y}) + P(\text{O})$$

---

## 4. Universal Set ($\Omega$)

The **Universal Set** ($\Omega$) contains **all possible outcomes**.

In this example:

$$\Omega = \{\text{Blue, Green, Red, Yellow, Orange}\}$$

Since every ball must belong to one of these colors, the total probability of the sample space is:

$$P(\Omega) = 1$$

This means there is a **100% chance** ($1.0$) that a picked ball will be one of these five colors.

---

## Key Takeaways

* Probability always lies between **0 and 1**.
* Sigmoid outputs values between **0 and 1** because they represent probabilities.
* For **disjoint (mutually exclusive) events**, probabilities add up directly.
* The **Universal Set** contains all possible outcomes, so $P(\Omega) = 1$.
* These concepts form the foundation for understanding **random variables** and **Cross-Entropy Loss** used in machine learning.
