# **Guesswork for Learning the Sigmoid Parameters ($w$ and $b$)**

In this lecture, the instructor introduces a simple guess-and-check approach to help build intuition for how a learning algorithm updates the sigmoid's parameters. This is not the actual learning algorithm, but a stepping stone toward understanding optimization.

---

## 1. Goal of Learning

The objective is to find the best values of $w$ and $b$ so that the sigmoid function fits the training data.

A good sigmoid function should satisfy:

* For every training input ($x$), the predicted output ($\hat{y}$) should be as close as possible to the true output ($y$).
* This means the loss on the training data should be at a minimum.

---

## 2. Start with Random Parameters

Since we don't know the correct values of $w$ and $b$, we initialize them.

The instructor starts with:

$$w = 0, \qquad b = 0$$

The sigmoid becomes:

$$\hat{y} = \frac{1}{1 + e^0} = \frac{1}{2} = 0.5$$

So no matter what input is given:

$$\boxed{\hat{y} = 0.5}$$

This produces a flat horizontal line, which clearly does not fit the training data.

---

## 3. Guessing a Better Weight

The training points show that:

* As $x$ increases, $y$ also increases.
* So the sigmoid should have a positive slope.

The instructor guesses:

$$w = 1$$

The curve now starts increasing.

Trying:

* $w = 2$
* $w = 3$

makes the sigmoid steeper, bringing it closer to the desired shape.

> **Observation:**
> Increasing $w$ increases the slope, making the sigmoid resemble the training data more closely.

---

## 4. Adjusting the Bias

Although the slope is now reasonable, the sigmoid is still in the wrong position.

The instructor recalls that the point where the sigmoid output equals $0.5$ is given by:

$$x = -\frac{b}{w}$$

To shift the sigmoid to the right, $b$ must become more negative.

So the instructor gradually decreases $b$:

* $b = -2$
* $b = -4$
* $b = -6$
* $b = -9$

Each update shifts the sigmoid closer to the data points.

---

## 5. Fine-Tuning

After moving the sigmoid near the training points, the instructor makes small adjustments to $w$ and $b$.

Eventually, a combination of parameters is found where the sigmoid passes very close to all the training examples.

At this stage:

* Predictions closely match the true outputs.
* The loss becomes very small.

---

## 6. What Was Actually Happening?

Each update followed the same pattern:

$$\boxed{w_{\text{new}} = w_{\text{old}} + \Delta w}$$

$$\boxed{b_{\text{new}} = b_{\text{old}} + \Delta b}$$

**Examples:**

| Current ($w, b$) | Change ($\Delta w, \Delta b$) | New ($w, b$) |
| :--- | :--- | :--- |
| $(0, 0)$ | $(+1, 0)$ | $(1, 0)$ |
| $(1, 0)$ | $(+1, 0)$ | $(2, 0)$ |
| $(2, 0)$ | $(+1, 0)$ | $(3, 0)$ |
| $(3, 0)$ | $(0, -2)$ | $(3, -2)$ |
| $(3, -2)$ | $(0, -2)$ | $(3, -4)$ |
| $\dots$ | $\dots$ | $\dots$ |

This is the basic idea behind parameter updates.

---

## 7. Why Guesswork Fails

Although the guess-and-check method works for this simple example, it has major limitations:

* It relies entirely on manual intuition.
* It works only because the data is one-dimensional and easy to visualize.
* For high-dimensional data (10, 100, or thousands of features), visualization is impossible.
* Guessing parameter updates becomes impractical and inefficient.
* The updates can overshoot the best solution, requiring corrections.

Therefore, guesswork cannot scale to real machine learning problems.

---

## 8. Need for a Better Learning Algorithm

Instead of guessing $\Delta w$ and $\Delta b$, we want a systematic method that:

* Uses the loss function,
* Determines the correct direction to move,
* Chooses appropriate update sizes,
* Reduces the loss at every step.

This motivates the need for a principled optimization algorithm (such as Gradient Descent), which will be introduced in later lectures.

---

## Guesswork vs. Real Learning

| Guesswork | Real Learning Algorithm |
| :--- | :--- |
| Manual updates | Automatic updates |
| Based on intuition | Guided by the loss function |
| Easy only in 1D | Works in any number of dimensions |
| Can overshoot the solution | Moves systematically toward the minimum loss |
| Not practical | Used in real machine learning |

---

## Key Takeaways

* The goal is to learn $w$ and $b$ so that the sigmoid curve best fits the training data and minimizes the loss.
* Starting from random values, the instructor manually adjusted $w$ (to control the slope) and $b$ (to shift the curve) until the sigmoid matched the data.
* Each update followed the form:

$$w \leftarrow w + \Delta w, \qquad b \leftarrow b + \Delta b$$

* This guess-and-check approach builds intuition but is not suitable for real-world machine learning.
* A proper learning algorithm should use the loss function to decide how much and in which direction to update the parameters automatically. This sets the stage for learning optimization methods like Gradient Descent.
