# **Taylor Series for Finding the Learning Algorithm**

This lecture explains how Taylor Series helps derive a principled way to update model parameters so that the loss decreases after every update.

---

## 1. Goal Recap

The objective is to update the parameters $w$ and $b$ so that the new loss is smaller than the current loss. Instead of guessing updates, we want a mathematically justified update rule:

$$\boxed{L(\text{new parameters}) < L(\text{current parameters})}$$

---

## 2. Loss Depends on Both $w$ and $b$

The prediction is:

$$\hat{y} = \sigma(wx + b)$$

Since changing either $w$ or $b$ changes $\hat{y}$, the error and total loss change as well:

$$L = L(w, b)$$

Instead of writing two variables repeatedly, we combine them into a single parameter vector:

$$\boldsymbol{\theta} = \begin{bmatrix} w \\ b \end{bmatrix}$$

Now, the loss can be written simply as:

$$L = L(\boldsymbol{\theta})$$

---

## 3. Taylor Series for Vectors

Earlier, Taylor Series was introduced for a single variable. Extended to vector parameter spaces, it is expressed as:

$$L(\boldsymbol{\theta} + \eta \mathbf{u}) = L(\boldsymbol{\theta}) + \eta \mathbf{u}^T \nabla L(\boldsymbol{\theta}) + \text{higher-order terms}$$

where:

* $\eta$ = learning rate
* $\mathbf{u}$ = unit vector representing the update direction
* $\nabla L(\boldsymbol{\theta})$ = gradient vector of the loss function

---

## 4. Ignoring Higher-Order Terms

The learning rate is chosen to be very small (e.g., $\eta = 0.001$). Consequently:

$$\eta^2 = 10^{-6}, \qquad \eta^3 = 10^{-9}$$

Because these higher-order values are extremely tiny, their terms contribute negligibly and can be safely ignored:

$$\boxed{L(\boldsymbol{\theta} + \eta \mathbf{u}) \approx L(\boldsymbol{\theta}) + \eta \mathbf{u}^T \nabla L(\boldsymbol{\theta})}$$

This linear approximation is the foundation for deriving **Gradient Descent**.

---

## 5. New Objective

To ensure that the loss decreases after every update step, we require:

$$L(\boldsymbol{\theta} + \eta \mathbf{u}) < L(\boldsymbol{\theta})$$

Using our Taylor expansion approximation, this reduces to choosing a direction $\mathbf{u}$ such that:

$$\boxed{\mathbf{u}^T \nabla L(\boldsymbol{\theta}) < 0}$$

If this dot product is negative, the new loss is guaranteed to be smaller than the current loss.

---

## 6. Derivatives $\rightarrow$ Partial Derivatives $\rightarrow$ Gradient

### (a) Derivative (Single Variable)

For a single-variable function $f(w) = w^3$:

$$\frac{df}{dw} = 3w^2$$

### (b) Partial Derivative (Multiple Variables)

For a multi-variable function $f(w, b) = w^3 + b^2$:

* **With respect to $w$** (treat $b$ as constant):

$$\frac{\partial f}{\partial w} = 3w^2$$

* **With respect to $b$** (treat $w$ as constant):

$$\frac{\partial f}{\partial b} = 2b$$

These are called **partial derivatives** because the function depends on multiple independent inputs.

---

## 7. Gradient

The **gradient** is simply a column vector containing all partial derivatives:

$$\nabla f = \begin{bmatrix} \frac{\partial f}{\partial w} \\[6pt] \frac{\partial f}{\partial b} \end{bmatrix}$$

Similarly, for the loss function:

$$\nabla L(\boldsymbol{\theta}) = \begin{bmatrix} \frac{\partial L}{\partial w} \\[6pt] \frac{\partial L}{\partial b} \end{bmatrix}$$

The gradient vector points in the direction of steepest increase of the loss function..

---

## 8. Why is $\mathbf{u}^T \nabla L$ a Scalar?

$\mathbf{u}$ is an update direction vector:

$$\mathbf{u} = \begin{bmatrix} \Delta w \\ \Delta b \end{bmatrix}$$

The gradient is also a vector:

$$\nabla L = \begin{bmatrix} \frac{\partial L}{\partial w} \\[6pt] \frac{\partial L}{\partial b} \end{bmatrix}$$

Taking the transpose of $\mathbf{u}$ yields a row vector $\mathbf{u}^T = [\Delta w, \Delta b]$. Multiplying it by the gradient vector gives:

$$\mathbf{u}^T \nabla L = \Delta w \frac{\partial L}{\partial w} + \Delta b \frac{\partial L}{\partial b}$$

This is a standard **dot product**, which always evaluates to a single real number (scalar), keeping the Taylor expansion equation mathematically valid.

---

## Summary Table

| Concept | Expression |
| :--- | :--- |
| **Parameter Vector** | $\boldsymbol{\theta} = [w, b]^T$ |
| **First-Order Taylor Expansion** | $L(\boldsymbol{\theta} + \eta \mathbf{u}) \approx L(\boldsymbol{\theta}) + \eta \mathbf{u}^T \nabla L(\boldsymbol{\theta})$ |
| **Gradient Vector** | $\nabla L(\boldsymbol{\theta}) = \left[ \frac{\partial L}{\partial w}, \frac{\partial L}{\partial b} \right]^T$ |
| **Descent Condition** | $\mathbf{u}^T \nabla L(\boldsymbol{\theta}) < 0$ |

---

## Key Takeaways

* Loss depends on both $w$ and $b$, so parameters are represented as a vector $\boldsymbol{\theta}$.
* Taylor Series approximates how the loss changes after a small parameter update step.
* Because the learning rate ($\eta$) is small, higher-order terms can be safely ignored.
* The linear approximation is:

$$L(\boldsymbol{\theta} + \eta \mathbf{u}) \approx L(\boldsymbol{\theta}) + \eta \mathbf{u}^T \nabla L(\boldsymbol{\theta})$$

* The gradient $\nabla L$ is a vector collecting all partial derivatives of the loss function.
* The learning objective simplifies to finding an update direction $\mathbf{u}$ that satisfies $\mathbf{u}^T \nabla L < 0$.

## What's Next?

The upcoming lecture answers the main question: **How do we choose the optimal update direction $\mathbf{u}$?** 

It demonstrates that setting $\mathbf{u}$ directly opposite to the gradient maximizes loss reduction, resulting in the classic **Gradient Descent** update rule:

$$\boxed{\boldsymbol{\theta}_{\text{new}} = \boldsymbol{\theta} - \eta \nabla L(\boldsymbol{\theta})}$$
