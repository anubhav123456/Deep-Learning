# Lecture Summary: **Choosing the Best Update Direction (Gradient Descent)**

This lecture derives the **Gradient Descent** update rule using the Taylor Series approximation and dot product geometry.

---

## 1. Goal

Previously, we obtained the linear approximation:

$$L(\boldsymbol{\theta} + \eta \mathbf{u}) \approx L(\boldsymbol{\theta}) + \eta \mathbf{u}^T \nabla L(\boldsymbol{\theta})$$

where:

* $L(\boldsymbol{\theta})$ = current loss
* $\mathbf{u}$ = unit vector representing the update direction
* $\eta$ = learning rate
* $\nabla L(\boldsymbol{\theta})$ = gradient vector

Our objective is:

$$\boxed{L(\boldsymbol{\theta} + \eta \mathbf{u}) < L(\boldsymbol{\theta})}$$

meaning the loss should decrease after every update.

---

## 2. Condition for Loss to Decrease

Subtracting the current loss $L(\boldsymbol{\theta})$ from both sides:

$$L(\boldsymbol{\theta} + \eta \mathbf{u}) - L(\boldsymbol{\theta}) \approx \eta \mathbf{u}^T \nabla L(\boldsymbol{\theta})$$

Since the learning rate $\eta$ is always positive ($\eta > 0$), the condition for reducing loss simplifies to:

$$\boxed{\mathbf{u}^T \nabla L(\boldsymbol{\theta}) < 0}$$

So, we need to choose an update direction vector $\mathbf{u}$ such that its dot product with the gradient vector is negative.

---

## 3. Understanding the Dot Product

The dot product of two vectors can be written geometrically as:

$$\mathbf{u}^T \nabla L(\boldsymbol{\theta}) = \|\mathbf{u}\| \|\nabla L(\boldsymbol{\theta})\| \cos\beta$$

where:

* $\|\mathbf{u}\|$ = magnitude of the direction vector
* $\|\nabla L(\boldsymbol{\theta})\|$ = magnitude of the gradient
* $\beta$ = angle between the update direction $\mathbf{u}$ and the gradient $\nabla L(\boldsymbol{\theta})$

---

## 4. Which Angle is Best?

We want to maximize the decrease in loss, which means making $\mathbf{u}^T \nabla L(\boldsymbol{\theta})$ as negative as possible.

Since vector magnitudes are non-negative, the sign and magnitude of the dot product depend entirely on $\cos\beta$:

* $\cos(0^\circ) = 1$
* $\cos(90^\circ) = 0$
* $\cos(180^\circ) = -1$

The minimum (most negative) value of $\cos\beta$ is $-1$, which occurs when $\beta = 180^\circ$.

---

## 5. Main Result

The maximum decrease in loss occurs when the update direction $\mathbf{u}$ points exactly opposite ($180^\circ$) to the gradient vector:

$$\boxed{\mathbf{u} = -\nabla L(\boldsymbol{\theta})}$$

This is the core geometric intuition behind Gradient Descent.

---

## 6. Why Opposite to the Gradient?

* The gradient vector points in the direction of the **steepest increase** in the loss function.
* Moving along the gradient increases the loss.
* Moving **opposite to the gradient** decreases the loss at the fastest possible rate.

---

## 7. Gradient Descent Update Rule

Combining the opposite-gradient direction with the learning rate gives the vector parameter update rule:

$$\boxed{\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta \nabla L(\boldsymbol{\theta}_t)}$$

### Updating Individual Parameters

For weight $w$:

$$\boxed{w_{t+1} = w_t - \eta \frac{\partial L}{\partial w}}$$

For bias $b$:

$$\boxed{b_{t+1} = b_t - \eta \frac{\partial L}{\partial b}}$$

---

## 8. Complete Learning Process

The learning algorithm executes the following iterative pipeline:

1. Initialize $w$ and $b$ (often randomly or with small values).
2. Compute predictions $\hat{y}$.
3. Compute the loss $L$.
4. Compute the partial derivatives (gradients): $\frac{\partial L}{\partial w}$ and $\frac{\partial L}{\partial b}$.
5. Update parameters:

$$w \leftarrow w - \eta \frac{\partial L}{\partial w}$$

$$b \leftarrow b - \eta \frac{\partial L}{\partial b}$$

6. Repeat steps 2–5 until the loss reaches a minimum or stops decreasing significantly.

## Key Takeaways

* To ensure the loss decreases after every parameter update, we require $\mathbf{u}^T \nabla L < 0$.
* The dot product depends on the angle $\beta$ between the update direction and the gradient.
* The maximum decrease in loss occurs when $\beta = 180^\circ$, meaning the update direction is directly opposite the gradient vector:

$$\mathbf{u} = -\nabla L(\boldsymbol{\theta})$$

* This leads directly to the standard Gradient Descent update rule:

$$\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta \nabla L(\boldsymbol{\theta}_t)$$

* For individual parameters:

$$w_{t+1} = w_t - \eta \frac{\partial L}{\partial w}, \qquad b_{t+1} = b_t - \eta \frac{\partial L}{\partial b}$$

> **In One Sentence:** Gradient Descent updates parameters in the direction opposite to the gradient because the gradient points toward the steepest increase in loss, making the negative gradient direction the fastest path to minimize loss.
