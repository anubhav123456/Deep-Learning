# **Complete Gradient Descent Learning Algorithm**

This lecture brings together everything learned so far and presents the complete training (learning) algorithm for logistic regression using **Gradient Descent**.

---

## 1. Recap of the Gradient Descent Update Rule

From the previous lecture, we derived that the update direction should be opposite to the gradient:

$$\mathbf{u} = -\nabla L$$

Therefore, the parameter update vector becomes:

$$\boxed{\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta \nabla L(\boldsymbol{\theta}_t)}$$

where:

* $\boldsymbol{\theta} = \begin{bmatrix} w \\ b \end{bmatrix}$
* $\eta$ = learning rate
* $\nabla L$ = gradient vector:

$$\nabla L = \begin{bmatrix} \frac{\partial L}{\partial w} \\ \frac{\partial L}{\partial b} \end{bmatrix}$$

### Individual Update Equations

For the weight $w$:

$$\boxed{w_{t+1} = w_t - \eta \frac{\partial L}{\partial w}}$$

For the bias $b$:

$$\boxed{b_{t+1} = b_t - \eta \frac{\partial L}{\partial b}}$$

## 2. Ingredients Needed for Learning

The complete machine learning setup now contains:

* **Data:** Input-output pairs $(x, y)$
* **Task:** Regression or binary classification
* **Model:** Sigmoid (Logistic Regression)
* **Loss Function:** Squared Error Loss
* **Learning Algorithm:** Gradient Descent

---

## 3. Complete Training Algorithm

The lecture combines all these pieces into one iterative algorithm:

### Step 1: Initialize Parameters

Choose initial values for $w$ and $b$ (e.g., $w = 0, b = 0$, or random values).

### Step 2: Compute Predictions

For every training example, compute predictions using the current parameters:

$$\hat{y} = \frac{1}{1 + e^{-(wx + b)}}$$

### Step 3: Compute Loss

Calculate the total error across training samples:

$$L = \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2$$

This measures how well the current model fits the data.

### Step 4: Compute Gradients

Calculate the partial derivatives:

$$\frac{\partial L}{\partial w} \quad \text{and} \quad \frac{\partial L}{\partial b}$$

These gradients indicate the direction and magnitude of loss change.

### Step 5: Update Parameters

Apply the Gradient Descent update rules:

$$w \leftarrow w - \eta \frac{\partial L}{\partial w}$$

$$b \leftarrow b - \eta \frac{\partial L}{\partial b}$$

### Step 6: Repeat

Repeat steps 2–5 iteratively until a stopping criterion is met.

---

## 4. Role of PyTorch and TensorFlow

Computing gradients manually can be mathematically complex. Modern frameworks like **PyTorch** and **TensorFlow** automatically compute gradients using automatic differentiation (*autograd*).

In practice, you only need to:

1. Define the model architecture.
2. Compute predictions.
3. Compute the loss.
4. Call `loss.backward()` (PyTorch) to compute gradients automatically.
5. Update parameters using an optimizer.

---

## 5. Training Loop

The overall training process repeatedly executes:

```text
Initialize w, b

Repeat:
    Compute predictions (ŷ)
    Compute loss
    Compute gradients
    Update w and b

Until satisfied

```

Each epoch/iteration reduces the total loss.

---

## 6. When Should Training Stop?

The instructor outlines three common stopping criteria:

1. **Fixed Number of Iterations (Epochs):** Stop after a predetermined number of passes (e.g., 100 or 1000 epochs). This is the most common approach.
2. **Loss Below Threshold:** Stop when $L < \epsilon$ (e.g., $L < 0.001$).
3. **Parameter Convergence:** Stop when updates become negligible ($\Delta w \approx 0$ and $\Delta b \approx 0$).

---

## Complete Gradient Descent Workflow

```text
Initialize w, b
      │
      ▼
Compute predictions (ŷ)
      │
      ▼
Compute loss (L)
      │
      ▼
Compute gradients (∂L/∂w, ∂L/∂b)
      │
      ▼
Update parameters:
w = w - η (∂L/∂w)
b = b - η (∂L/∂b)
      │
      ▼
Repeat until convergence

```

## Key Takeaways

* The lecture combines model, loss, and gradient descent into one complete, functional learning algorithm.
* The training loop follows: **Initialize $\rightarrow$ Predict $\rightarrow$ Loss $\rightarrow$ Gradients $\rightarrow$ Update $\rightarrow$ Repeat**.
* Frameworks like PyTorch and TensorFlow handle gradient calculations automatically.
* Training stops based on a fixed epoch limit, target loss threshold, or parameter convergence.

> **One-Line Summary:** Gradient Descent trains a model by repeatedly computing predictions, measuring loss, calculating gradients, and updating parameters in the opposite direction of the gradient until reaching a minimum loss solution.
