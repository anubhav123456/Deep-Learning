# Perceptron Learning Algorithm – Intuition Behind the Update Rule (Lecture Summary)

This lecture explains **why the Perceptron update rules work geometrically**, not just how to apply them.

---

# 1. Goal of the Learning Algorithm

The Perceptron wants to learn the weight vector

[
\mathbf{w}=[w_1,w_2,\dots,w_n]
]

so that every training point is classified correctly.

The bias (b) is ignored in this lecture to simplify the explanation.

---

# 2. Two Important Vectors

We have:

### Weight Vector

[
\mathbf{w}=[w_1,w_2,\dots,w_n]
]

### Input Vector

[
\mathbf{x}=[x_1,x_2,\dots,x_n]
]

The prediction depends on their **dot product**.

---

# 3. Dot Product and Angle

From Linear Algebra:

[
\cos\theta=\frac{\mathbf{w}\cdot\mathbf{x}}
{||\mathbf{w}||,||\mathbf{x}||}
]

where

* (\theta) = angle between **w** and **x**

Since

[
||\mathbf{w}||>0,\qquad ||\mathbf{x}||>0
]

the denominator is **always positive**.

Therefore,

> **The sign of the dot product depends only on the numerator (\mathbf{w}\cdot\mathbf{x}).**

---

# 4. Relation Between Dot Product and Angle

| Dot Product | Cos θ    | Angle         |
| ----------- | -------- | ------------- |
| (>0)        | Positive | Acute (<90°)  |
| (=0)        | Zero     | 90°           |
| (<0)        | Negative | Obtuse (>90°) |

This is the most important concept in the lecture.

Simply remember:

* Positive dot product ⇒ Small angle
* Negative dot product ⇒ Large angle

---

# 5. Positive Training Point

Suppose the current point belongs to the **positive class**.

We want

[
\mathbf{w}\cdot\mathbf{x}\ge0
]

This means

* angle between **w** and **x**
* should be **less than 90°**

---

## What if the prediction is wrong?

Suppose

[
\mathbf{w}\cdot\mathbf{x}<0
]

Then

* angle > 90°
* prediction becomes negative
* but the point is actually positive.

So we need to **reduce the angle**.

---

# 6. Positive Update Rule

The Perceptron updates

[
\boxed{\mathbf{w}_{new}=\mathbf{w}+\mathbf{x}}
]

The lecture proves

[
\cos(\alpha_{new})

>

\cos(\alpha)
]

Why?

Because

[
\mathbf{w}_{new}
================

\mathbf{w}+\mathbf{x}
]

Taking dot product with x,

[
(\mathbf{w}+\mathbf{x})^T\mathbf{x}
===================================

\mathbf{w}^T\mathbf{x}
+
\mathbf{x}^T\mathbf{x}
]

Now,

[
\mathbf{x}^T\mathbf{x}
======================

x_1^2+x_2^2+\cdots+x_n^2
]

which is **always positive**.

Therefore,

[
\cos(\alpha_{new})

>

\cos(\alpha)
]

Since cosine increases,

the angle decreases.

So after every update,

```text
Before Update

w  ↖

      >90°

          ↘ x
```

↓

```text
After Update

w_new ↗

    < previous angle

       ↘ x
```

The weight vector slowly rotates **towards the positive example**.

Eventually,

[
\mathbf{w}\cdot\mathbf{x}\ge0
]

which is exactly what we wanted.

---

# 7. Negative Training Point

Suppose the point belongs to the **negative class**.

Desired condition:

[
\mathbf{w}\cdot\mathbf{x}<0
]

which means

angle > 90°.

---

## Wrong Prediction

Suppose

[
\mathbf{w}\cdot\mathbf{x}\ge0
]

Then

* angle < 90°
* model predicts positive
* actual class is negative.

So we must **increase the angle**.

---

# 8. Negative Update Rule

The Perceptron updates

[
\boxed{\mathbf{w}_{new}=\mathbf{w}-\mathbf{x}}
]

Now,

[
(\mathbf{w}-\mathbf{x})^T\mathbf{x}
===================================

## \mathbf{w}^T\mathbf{x}

\mathbf{x}^T\mathbf{x}
]

Again,

[
\mathbf{x}^T\mathbf{x}>0
]

Therefore,

[
\cos(\alpha_{new})
<
\cos(\alpha)
]

Cosine decreases.

Hence,

the angle increases.

Graphically,

```text
Before

w ↗

  <90°

x ↗
```

↓

```text
After

w_new ←

      > previous angle

x ↗
```

The weight vector rotates **away from the negative point**.

Eventually,

[
\mathbf{w}\cdot\mathbf{x}<0
]

which is exactly the desired condition.

---

# 9. Intuition

The Perceptron does **not randomly change the weights**.

Instead,

it changes the **direction** of the weight vector.

* Positive example → Move **towards** it.
* Negative example → Move **away** from it.

This gradually improves classification.

---

# 10. Final Intuition

Imagine **w** as an arrow.

Every time:

### Correct Positive

Nothing changes.

---

### Wrong Positive

Move the arrow **towards** that point.

[
\mathbf{w}=\mathbf{w}+\mathbf{x}
]

---

### Wrong Negative

Move the arrow **away** from that point.

[
\mathbf{w}=\mathbf{w}-\mathbf{x}
]

Repeat this for every training sample.

Eventually, if the data is linearly separable, the weight vector points in a direction that correctly separates positive and negative examples.

---

# Key Takeaways

* The Perceptron learning rule has a **geometric interpretation** based on the angle between the **weight vector** and the **input vector**.
* The sign of the dot product (\mathbf{w}\cdot\mathbf{x}) determines the angle:

  * Positive → angle < 90°
  * Negative → angle > 90°
* For a **misclassified positive point**, update:
  [
  \mathbf{w}_{new}=\mathbf{w}+\mathbf{x}
  ]
  This increases the cosine, decreases the angle, and rotates the weight vector **towards** the positive example.
* For a **misclassified negative point**, update:
  [
  \mathbf{w}_{new}=\mathbf{w}-\mathbf{x}
  ]
  This decreases the cosine, increases the angle, and rotates the weight vector **away from** the negative example.
* Repeating these updates gradually moves the decision boundary toward one that correctly classifies all linearly separable training points.
