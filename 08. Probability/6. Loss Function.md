# Why Do We Need Probability-Based Loss Functions?

This lecture connects **probability theory** with **classification problems** and explains why we eventually need a special loss function for comparing probability distributions.

---

### 1. Quick Recap: Discrete Random Variables

The course mainly deals with **discrete random variables**.

For example, suppose a random variable $X$ represents the color of a ball. It can take three values:

$$X \in \{\text{Red}, \text{Green}, \text{Blue}\}$$

A probability distribution tells us the probability of each possible value:

$$P(X) = [0.25,\ 0.40,\ 0.35]$$

This means:

* **Red:** $25\%$
* **Green:** $40\%$
* **Blue:** $35\%$

And all probabilities must sum to $1$:

$$0.25 + 0.40 + 0.35 = 1$$

---

### 2. The Urn Example

Imagine an urn containing **1000 balls**:

* 250 Red
* 400 Green
* 350 Blue

Therefore, the **true probability distribution** is:

$$y = [0.25,\ 0.40,\ 0.35]$$

Now, your friend is only allowed to **look inside the urn**, not count every ball. Based on what they observe, they estimate:

$$\hat{y} = [0.30,\ 0.30,\ 0.40]$$

So now we have:

* $y$ $\rightarrow$ **True distribution**
* $\hat{y}$ $\rightarrow$ **Predicted/estimated distribution**

The important question is:

> **How wrong is the predicted distribution compared to the true distribution?**

---

### 3. Can We Use Squared Error Loss?

One simple approach is to treat both distributions as normal vectors and calculate:

$$\text{Loss} = \sum_{i=1}^{3}(y_i - \hat{y}_i)^2$$

If the prediction is exactly correct ($\hat{y} = y = [0.25, 0.40, 0.35]$), then:

$$\text{Loss} = 0$$

So yes, **Squared Error Loss can measure the difference** between the true and predicted values.

---

### 4. But There Is a Problem

Squared Error treats these values like just **three ordinary numbers**.

However, probabilities have special properties:

$$0 \leq P \leq 1$$

and:

$$\sum_i P_i = 1$$

Therefore, a probability distribution is not just any random vector.

The lecturer's main argument is:

> **Since we are comparing probability distributions, we should ideally use a loss function specifically designed for probabilities rather than simply using Squared Error.**

---

### 5. Where This Is Leading

The chapter is building toward this journey:

$$\text{Classification} \longrightarrow \text{Model produces probabilities} \longrightarrow \text{True probability distribution} \longrightarrow \text{Compare the two distributions} \longrightarrow \text{Probability-based Loss Function}$$

In the upcoming videos, the instructor will first explain **why classification models actually deal with probabilities**.

Then, once that is established, the course will derive a better loss function for comparing:

$$\text{True Distribution } (y) \quad \text{vs.} \quad \text{Predicted Distribution } (\hat{y})$$

This is essentially the path toward understanding **Cross-Entropy Loss**.

---

### One-Line Takeaway

> **Squared Error can compare two probability distributions, but it ignores the special mathematical nature of probabilities. Therefore, for classification problems, we need a loss function designed specifically for probability distributions.**
