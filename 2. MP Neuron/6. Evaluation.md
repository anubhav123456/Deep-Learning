# Evaluation of the McCulloch-Pitts (MP) Neuron

This lecture explains the **final step** in the machine learning pipeline: **Evaluation**.

---

# 1. Recap of the First Five Steps

By this point, we have completed:

* ✅ Data
* ✅ Task
* ✅ Model (MP Neuron)
* ✅ Loss Function (Squared Error Loss)
* ✅ Learning Algorithm (Brute Force Search)

Using the training data, the model learned the optimal threshold:

$$\boxed{B = 5}$$

This threshold gave **zero loss on the training data**.

---

# 2. Why Do We Need Evaluation?

A model should not only perform well on the data it has already seen (training data).

We also need to check whether it performs well on **new, unseen data**, called the **test data**.

The instructor compares this to studying for an exam:

* **Training Data** → Reading and practicing from the textbook.
* **Test Data** → Solving new questions in an exam.

A good model should perform well on both.

---

# 3. Making Predictions on Test Data

The learned threshold is fixed:

B = 5


For each new test example:

1. Count how many input features are **1**.
2. Compare the sum with the threshold.

Decision rule:

$$\hat{y} = \begin{cases} 1, & \text{if } \sum x_i \ge 5 \\ 0, & \text{otherwise} \end{cases}$$

Examples:

* Sum = 4 → Predict **0**
* Sum = 5 → Predict **1**
* Sum = 6 → Predict **1**
* Sum = 3 → Predict **0**

---

# 4. Evaluating the Model

After making predictions, compare them with the true outputs.

The evaluation metric used for the MP neuron is **Accuracy**.

### Accuracy Formula

$$\boxed{\text{Accuracy} = \frac{\text{Number of Correct Predictions}}{\text{Total Number of Predictions}}}$$

---

# 5. Example

Suppose there are **4 test examples**.

The model predicts:

| Test Example | Correct? |
| ------------ | -------- |
| 1            | ✅        |
| 2            | ✅        |
| 3            | ❌        |
| 4            | ✅        |

Correct predictions = **3**

Total predictions = **4**

Therefore,

$$\text{Accuracy} = \frac{3}{4} = 0.75 = 75\%$$

So the MP neuron achieves an **accuracy of 75%** on the test data.

---

# 6. Key Idea

Training and evaluation are different:

* **Training:** Learn the threshold (B) using the training dataset.
* **Evaluation:** Test the learned threshold on unseen data to measure how well the model generalizes.

---

# Key Takeaways

* Evaluation is the **sixth and final step** in the machine learning pipeline.
* The MP neuron is first trained to find the best threshold (B).
* The learned threshold is then used to make predictions on **test data**.
* Model performance is measured using **Accuracy**:

$$\boxed{\text{Accuracy} = \frac{\text{Correct Predictions}}{\text{Total Predictions}}}$$

* In the lecture example:

  * Total test examples = **4**
  * Correct predictions = **3**
  * **Accuracy = 75%**
* A high accuracy on unseen test data indicates that the model has learned useful patterns rather than simply memorizing the training data.
