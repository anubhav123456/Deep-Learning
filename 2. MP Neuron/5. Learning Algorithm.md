# Learning Algorithm for the McCulloch-Pitts (MP) Neuron

This lecture explains **how the MP neuron learns its only parameter**, the **threshold (B)**.

---

# 1. Where Are We in the ML Pipeline?

So far, we have defined:

* ✅ Data
* ✅ Task (Binary Classification)
* ✅ Model (MP Neuron)
* ✅ Loss Function (Squared Error Loss)

Now we need a **Learning Algorithm**.

Its job is to find the value of **(B)** that minimizes the loss on the training data.

---

# 2. Goal of Learning

The MP neuron predicts:

$$\hat{y} = \begin{cases} 1 & \text{if } \sum x_i \ge B \\ 0 & \text{otherwise} \end{cases}$$

We want to choose the threshold **(B)** such that:

* Predictions match the true labels as closely as possible.
* Ideally, every prediction is correct, giving a **loss of 0**.

---

# 3. Why Only Certain Values of (B) Need to Be Checked?

Suppose there are **(n)** Boolean input features.

Each feature is either **0** or **1**.

Therefore, the sum of inputs can only be:

$$0, 1, 2, 3, \ldots, n$$

It **cannot** be:

* 2.5
* 7.8
* -1
* (n+5)

So the threshold (B) only needs to be tested over the **integer values from 0 to (n)**.

---

# 4. Learning Using Brute Force Search

Since there is only **one parameter ((B))**, the learning algorithm is very simple.

### Step 1

Choose a threshold.

Example:

[
B = 1
]

---

### Step 2

For every training example:

* Compute the sum of Boolean inputs.
* Check whether:

[
\sum x_i \ge B
]

If true:

* Predict **1**

Otherwise:

* Predict **0**

---

### Step 3

Compare predictions with the true outputs.

Compute the **Squared Error Loss**.

---

### Step 4

Repeat for every possible threshold.

For example:

* (B = 0)
* (B = 1)
* (B = 2)
* ...
* (B = n)

---

# 5. Example

Suppose there are **10 Boolean features**.

Then:

Possible thresholds are:

[
0,1,2,\ldots,10
]

For each threshold:

* Predict outputs.
* Compute total squared error.
* Record the loss.

Example:

| Threshold (B) | Loss  |
| ------------- | ----- |
| 1             | 4     |
| 2             | 3     |
| 3             | 2     |
| 4             | 1     |
| **5**         | **0** |
| 6             | 2     |
| 7             | 5     |
| 8             | 7     |
| 9             | 9     |
| 10            | 10    |

The smallest loss occurs at:

[
\boxed{B=5}
]

So the model learns:

> **Use threshold (B = 5)**

because it gives the best predictions on the training data.

---

# 6. Why Is This Called Brute Force?

The algorithm simply tries **every possible threshold**.

It does not use any optimization or mathematical shortcut.

It is called **brute force search** because it checks all candidate values one by one.

---

# 7. Is Brute Force Practical?

For the MP neuron, **yes**.

Why?

Because there is only **one parameter** to learn.

Even if there are:

* 100 features → test 101 thresholds.
* 1000 features → test 1001 thresholds.
* 10,000 features → test 10,001 thresholds.

This is still computationally manageable.

However, later neural networks have **millions of parameters**, so brute force becomes impossible, and more advanced optimization methods (like Gradient Descent) are needed.

---

# Key Takeaways

* The **learning algorithm** finds the best threshold (B).
* Since inputs are Boolean, the sum of inputs ranges only from **0 to (n)**.
* Therefore, only thresholds in **0 to (n)** need to be tested.
* The MP neuron learns using a **Brute Force Search**:

  1. Try a threshold.
  2. Predict outputs.
  3. Compute Squared Error Loss.
  4. Repeat for all thresholds.
  5. Choose the threshold with the **minimum loss**.
* This approach works because the MP neuron has only **one learnable parameter**.
