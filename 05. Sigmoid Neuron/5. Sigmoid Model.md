# Effect of Weights ($w$) and Bias ($b$) on the Sigmoid Function

This lecture explains how changing the weight ($w$) and bias ($b$) changes the shape and position of the sigmoid curve. Understanding this is important because, during training, the learning algorithm updates these parameters to fit the data.

---

## 1. Sigmoid Function

For one input, the sigmoid function is:

$$\boxed{\hat{y} = \frac{1}{1 + e^{-(wx + b)}}}$$

where:

* $x$ = input
* $w$ = weight
* $b$ = bias

---

## 2. Effect of Weight ($w$)

### (a) Sign of $w$

* **Positive $w$**: The sigmoid curve increases from 0 to 1.
* **Negative $w$**: The sigmoid curve decreases from 1 to 0.

So, the sign of the weight determines the direction (slope) of the sigmoid curve.

### (b) Magnitude of $w$

The absolute value of $w$ controls how steep the curve is.

* **Small $|w|$** (e.g., $0.3$) $\rightarrow$ Gradual, smooth transition.
* **Large $|w|$** (e.g., $3$ or $4$) $\rightarrow$ Very steep transition.

**Examples:**

* $w = 0.3 \rightarrow$ Gentle increasing curve.
* $w = 4 \rightarrow$ Very sharp increasing curve.
* $w = -0.3 \rightarrow$ Gentle decreasing curve.
* $w = -4 \rightarrow$ Very sharp decreasing curve.

> **Key Point:**
> * Sign of $w \rightarrow$ Direction of the curve.
> * Magnitude of $w \rightarrow$ Steepness of the curve.

---

## 3. Effect of Bias ($b$)

The bias shifts the sigmoid curve left or right.

The midpoint of the sigmoid occurs when:

$$\hat{y} = 0.5$$

This happens when:

$$wx + b = 0$$

or

$$\boxed{x = -\frac{b}{w}}$$

This value tells us where the center of the sigmoid lies.

### If $b$ Changes (Assuming $w$ is positive)

* **Increasing $b$**: Shifts the curve left.
* **Decreasing (making more negative) $b$**: Shifts the curve right.

> **Notice:**
> * The shape of the sigmoid remains the same.
> * Only its position changes.

---

## 4. Why This Matters

During training, the learning algorithm continuously updates $w$ and $b$ to minimize the loss function.

As these parameters change:

* The sigmoid curve rotates (changes slope).
* The curve becomes steeper or flatter.
* The midpoint shifts left or right.

Eventually, the algorithm finds the parameter values that best fit the training data.

---

## Summary Table

| Parameter | Effect |
| :--- | :--- |
| **Sign of $w$** | Determines whether the curve increases or decreases |
| **Magnitude of $w$** | Controls how steep or flat the curve is |
| **Bias ($b$)** | Shifts the entire curve left or right |
| **Midpoint** | Occurs at $x = -\frac{b}{w}$, where output = $0.5$ |

---

## Key Takeaways

* The weight ($w$) controls both the direction and steepness of the sigmoid curve.
* The bias ($b$) shifts the sigmoid curve horizontally without changing its shape.
* The midpoint of the sigmoid is always at:

$$\boxed{x = -\frac{b}{w}}$$

* During model training, the learning algorithm adjusts $w$ and $b$ to minimize the loss, making it essential to understand how these parameters affect the sigmoid function.
